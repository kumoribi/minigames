# しあわせ投資録 v3（信用枠方式）

24ラウンドで幸福を集める、2～4人の投資ボードゲーム。人間＋AIまたは同端末交代。ミニゲーム集トップから起動し、準備後に「人生を開始」を押す。

## 新しいルール

- 初期資金500万円、幸福初期価格10万円。会社6社、不動産6種類（400万円～10億円）。基礎収入40万円、家賃は物件価格の5%。
- 株式は手番の最初に選んだ1銘柄だけ何回でも売買可能。他の主行動とは併用できない。購入後価格／除去後価格で売買、取得原価固定。
- 資産は拘束しない信用枠方式。自己現金評価=max(0,現金−全債務)。信用上限=株の全処分評価50%＋物件取得額50%＋自己現金100%。追加融資枠=max(0,信用上限−全債務)。50万円・2契約の一律制限なし。
- 現金500万円から200万円借りれば、700万円すべて使えて残りの信用枠は300万円。借入中でも株を売買でき、物件もイベント時に売れる。資産が減った時は新規借入を制限し、即時の回収はしない。
- 銀行とプレイヤーの融資を同じカード市場へ配置。プレイヤーは元本と0～20%の金利を自由設定し、掲載時に元本を確保しない。
- 貸し手の資金不足では他の融資カードから低金利順に強制調達。循環経路を除外し、不足分は緊急融資。確認画面で成立する連鎖契約を表示。
- 緊急融資は無担保20%／ラウンド。次の自分の手番末に返せなければ破産・脱落。借り直しで期限を延長できず、強制追加でも元の期限を維持。
- 他人の緊急融資は公開され、同額元本の高金利カードを場に置けば通常融資への借り換え先になる。緊急からの借り換えは20%同率も可。
- 金額は万円整数・割合の端数切り捨て。物件売却はイベント時のみ±20%、借入中でも物件は売れる。

## 保存と旧版

確定操作ごとにlife-investment-save-v3へ自動保存。タブ離脱でAIも停止し、手動で再開。旧キーlife-investment-save-v1・v2は上書きせず、legacy/とlegacy-v2/の旧ルールで続きから再開できる。新ルールは新規ゲームから適用する。端末間・ブラウザ間同期はない。

## 構成・検証

計算engine.js／カードcards.js／AI ai.js／保存storage.js／画面game.js。`node tests.cjs`で信用評価・資産の自由な使用・連続売買・市場・再帰融資・期限・脱落・互換性・33シナリオ（500シード完走を含む）を検証する。詳細はSPECIFICATION.md、TEST_SPECIFICATION.md。

Edge実ブラウザで融資確認・取消・成立・期限の保存再開・脱落を確認。5画面幅×3市場の15条件、9ゲーム起動、v1・v2・v3のオフライン起動を確認。実機タッチ・音・長時間性能・人間の戦略性評価は未確認。AIは有限の短い売買バッチを選び、最適戦略ではない。億単位物件への到達性と幸福先行の優位は調整対象。
