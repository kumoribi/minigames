# しあわせ投資録

株式・不動産・融資を使い、24ラウンドの人生で幸福を集めるブラウザボードゲーム。2～4人の対戦AI／同端末交代に対応。初版の金額・頻度は調整対象。

## 起動と遊び方

ミニゲーム集の「しあわせ投資録」から起動。ローカルでは静的HTTPサーバーから開く。人数・方法を選んで準備し、「人生を開始」を押す。各手番に主行動1回と金融操作1回が可能。行動後にターン終了する。

- 株価はNPCを含む株の枚数。追加後価格で買い、除去後価格で売る。取得原価は固定。
- 幸福は現在表示の価格で買い、売れない。NPCも価格を上げる。幸福最多が勝ち、同点は共同勝利。
- 不動産は入居中だけ家賃。売却イベントの受益者だけ1件を購入額±20%で売れる。強制処分はしない。
- 融資は株処分額の50%・合計50万円・2契約まで。金融操作から借入・返済・借り換え・貸付ができる。利息はラウンド末、契約ごとに端数切り捨て。
- 金額はすべて万円単位の整数。金融緩和の10万円・5%は利息0万円になるが、元本・担保・契約上限は維持する。
- 利払い不足なら株売却・緊急借入1回で救済。資産整理では幸福と物件を保持し残債を以後の収入で返す。

## 保存・停止

操作確定ごとにブラウザへ自動保存。再読み込み後は続きから／新規を選ぶ。タブを離れるとAIも止まり、手動で再開。ブラウザ・端末間同期なし。保存不可・不対応データ・別タブ更新を検知した場合は停止して理由を表示する。保存形式やルール版の違うデータは黙って移行しない。

## 構成・検証

cards.jsはカードと調整値、engine.jsは純粋な状態遷移、ai.jsは公開情報による判断、storage.jsは保存と衝突検知、game.jsは入力・表示・演出。仕様と90条件の検証計画はSPECIFICATION.mdとTEST_SPECIFICATION.md。

`node tests.cjs`で価格・所有権・イベント売却・万円切り捨て・担保・貸付・借り換え・資産整理・勝敗・500シードの24ラウンド完走を確認する。

## 残る制約

オンライン対戦・端末同期は対象外。AIは単純方針で、金融機能の積極利用はしない。最適戦略や人間によるバランス評価は今後の調整対象。実機タッチ・実機効果音・長時間性能は未確認。効果音は初期OFF、演出軽減はOS設定を反映し、個別設定はセッション内のみ。
