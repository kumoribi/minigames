# しあわせ投資録 v2

24ラウンドで幸福を集める、2～4人の投資ボードゲーム。人間＋AIまたは同端末交代。ミニゲーム集トップから起動し、準備後に「人生を開始」を押す。

## 新しいルール

- 初期資金500万円、幸福初期価格10万円。会社6社、不動産6種類（400万円～10億円）。基礎収入40万円、家賃は物件価格の5%。
- 株式は手番の最初に選んだ1銘柄だけ何回でも売買可能。他の主行動とは併用できない。購入後価格／除去後価格で売買、取得原価固定。
- 融資総額50万円・2契約の制限は廃止。未使用の株評価50%＋物件取得額50%＋自己現金100%が枠。担保資産は再利用・支出・売却不可、完済で解除。
- 銀行とプレイヤーの融資を同じカード市場へ配置。プレイヤーは元本と0～20%の金利を自由設定し、掲載時に元本を確保しない。
- 貸し手の資金不足では他の融資カードから低金利順に強制調達。循環経路を除外し、不足分は緊急融資。確認画面で成立する連鎖契約を表示。
- 緊急融資は無担保20%／ラウンド。次の自分の手番末に返せなければ破産・脱落。借り直しで期限を延長できず、強制追加でも元の期限を維持。
- 他人の緊急融資は公開され、同額元本の高金利カードを場に置けば通常融資への借り換え先になる。緊急からの借り換えは20%同率も可。
- 金額は万円整数・割合の端数切り捨て。物件売却はイベント時のみ±20%、担保物件は不可。

## 保存と旧版

確定操作ごとにlife-investment-save-v2へ自動保存。タブ離脱でAIも停止し、手動で再開。旧キーlife-investment-save-v1は上書きせず、legacy/の旧ルールで続きから再開できる。新ルールは新規ゲームから適用する。端末間・ブラウザ間同期はない。

## 構成・検証

計算engine.js／カードcards.js／AI ai.js／保存storage.js／画面game.js。`node tests.cjs`で担保・連続売買・市場・再帰融資・期限・脱落・互換性・500シード完走を検証する。詳細はSPECIFICATION.md、TEST_SPECIFICATION.md。

Edge実ブラウザで融資確認・取消・成立・期限の保存再開・脱落を確認。5画面幅×3市場の15条件、9ゲーム起動、新旧ルールのオフライン起動を確認。実機タッチ・音・長時間性能・人間の戦略性評価は未確認。AIは有限の短い売買バッチを選び、最適戦略ではない。億単位物件への到達性と幸福先行の優位は調整対象。
