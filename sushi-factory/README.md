# にゃんこ寿司工場

調理台の自動搬送・猫の仕分け・寿司レーンで、食材の入荷・加工・提供を自動化するブラウザゲーム。外部ライブラリ・画像・音声・ネットワークAPIは不要。

## 起動・検証

ゲーム集をHTTPで配信し、`sushi-factory/` を開く。`node sushi-factory/tests.cjs` で44件のロジックテストを実行する。

## 実装仕様

- `engine.js`: 250ms固定ステップ。入力のスナップショットにより新しい食材が同一ステップ内に再搬送されることを防止。競合時は走査開始位置を交代し、受け渡し元を一度だけ消費する。
- `game.js`: Canvas描画、入力、保存、表示更新。描画速度と計算速度は独立。猫・設備・寿司をCanvasで描く。
- レーン1マス1個。立体交差のみ縦横各1個。分岐は直進と左折。フィルター指定時は一致品だけ左折し、詰まっても別経路へ流さない。
- 猫は隣接1マスから隣接1マスへ運ぶ。取る側・渡す側は別方向。フィルターを指定すると一致する食材だけ運ぶ。猫なしでも調理台の自動搬送で生産できる。
- 入荷箱は無料で6ステップごとに食材1個、最大4個。調理台は各必要材料を最大4個、完成品を最大4個保管する。
- 炊飯6・仕込み4・握り8・巻き10ステップ。調理開始時に材料を確保し、完成品が満杯なら待つ。
- 米→シャリ。まぐろ／サーモン→各ネタ。きゅうり→切ったきゅうり。シャリと各ネタ→握り寿司。シャリ・切ったきゅうり・海苔→かっぱ巻き。
- 建設費：レーン5、猫20、入荷箱40、調理台60、客席30、分岐器25、立体交差35円。撤去時に全額返却。内部の材料・完成品・調理途中の材料は廃棄。
- 初期資金500円と無料配置済みの設備。初期設備も撤去時は通常の建設費を返却する。レーン(9,5)だけ空けた導入配置（座標は0始まり）。
- 提供単価：まぐろ12・サーモン16・巻き22円。客席は上下左右に接するレーンの完成皿を搬送前に1ステップ1皿まで取る。分岐器も対象。立体交差は客席に接する軸の皿を取る。猫による直接配膳も可能。
- まぐろ20皿で350円・サーモンと分岐器解放。サーモン20皿で500円・巻き寿司と立体交差解放。巻き20皿で700円・自由建設。報酬は段階ごと一回。
- 敷地は14×10→20×14→24×18→28×20。ランダム生成なし。
- 開始・復元・新規・ヘルプ・リセット確認・タブ非表示で停止。オフライン生産なし。5秒ごと、建設・設定変更・停止時に `neko-sushi-factory-v1` へ保存。壊れた保存データは上書きせず、新規開始でのみ置換する。
- 全体表示、盤面移動、ホイール／2本指拡大縮小、レーン連続配置、キーボード建設。スマホ初期マスは44px以上。全体表示では縮小する。
- OSのモーション軽減と独自設定に対応。音なし。流れる向き・待機理由・解放条件を文字でも表示。

## 検証範囲

自動テストは導入ライン、全3注文の実搬送、容量、合流、分岐、交差、材料消費、提供と報酬の重複防止、撤去返金、保存復元、不正データ拒否を確認。合流・満杯搬送は複数の走査開始位置で確認する。

スマートフォン実機の性能・実機の2本指操作は別途確認が必要。ゲーム用の画面内テストとブラウザ幅検証はテスト仕様書に記録する。

## 盤面内UI（2026-11-04・画面v2）

- 盤面を画面幅・高さ全体に広げ、ページ全体のスクロールを禁止。ブラウザの安全領域と動的な表示高さに対応。
- 上部に資金・提供数・稼働／停止・メニュー、注文の進捗を重ねる。注文を選ぶと解放条件と報酬を表示。
- 下部に建設・移動・撤去・向き変更を常設。盤面内の隅に拡大縮小・全体表示を配置。
- 建設一覧・設備情報・注文詳細・メニューは排他的に開閉。建設設備を選ぶと一覧を閉じて配置モードへ移る。短い画面ではパネル内部だけをスクロールする。
- 移動モードで設備を選ぶと情報パネルを開き、選択設備を見える位置へ移動。閉じる操作とEscに対応。建設のたびに情報パネルを開かない。
- ヘルプ・新規開始・ゲーム集へのリンク・詳しい保存状況は☰メニューから操作。保存エラーは画面内通知と保存表示でも知らせる。
- 全体表示とキーボード選択の中心位置は、上部・下部の操作領域を避けて計算する。盤面はパネルの裏側も含め自由に移動できる。
- ドラッグの途中でパネルに入ったら配置を終了し、パネルで覆われたマスには連続配置しない。パネル上で指を離しても背後の配置・撤去を実行しない。
- 生産計算、費用、解放条件、当時の保存形式はv1。既存の保存を引き継ぐ。

## 共通調理台と客席（2026-11-05）

建設時の調理台は炊飯釜、仕込み台、握り台、巻き寿司台の4種。仕込み台はまぐろ・サーモン・きゅうりを、握り台はシャリと魚のネタを受け入れる。作れる品から順番に選び、両方の魚がそろえば交互に握る。入荷の段階解放、費用、調理時間は従来通り。

同じ保存キーで形式v1を読み込み、設置済みの専用台を共通台へ移行する。調理途中のレシピ・進捗、在庫、完成品、旧配置の配膳猫を引き継ぎ、次回保存は形式v2。新規配置では客席を完成皿レーンの横に置く。


### 客席の食事時間

客席は1皿取るとゲーム内で3秒間は食事中になります。その間、次の皿はレーンを通過し、猫からの直接配膳も待ちます。客席を選ぶと残り時間を確認できます。一時停止中は食事時間も止まり、保存後は残り時間から再開します。

## 設備の移設（2026-11-05）

- 盤面を動かす操作名を「画面移動」に変更。設備情報の「移設」で個別移設、操作バーの「範囲選択」で矩形内の設備を一括移設する。
- 範囲はドラッグまたは対角の2点をタップ。矢印キーとEnterでも指定できる。空きマスは選択に含めず、選択設備の最小座標を移動先の左上に合わせる。
- 移動先を選ぶと半透明の設備と緑の枠を表示。「確定」で一括反映。「取消」またはEscで元の配置を保持する。
- 敷地外や選択外の設備との衝突は赤い枠と具体的な理由を表示し、確定不可。選択した設備同士の元位置への移動は可能。途中まで移動することはない。
- 移設は無料。設備の向き・フィルター・在庫・搬送中の皿・調理途中・食事時間を保持する。
- 開始時に停止し、確定・取消後も停止したまま。移設中の「画面移動」でパンでき、「移設に戻る」で続ける。
- 未確定の選択は画面だけに保持し、自動保存は元の配置を保存。確定時に移設後の配置を保存する。保存形式v2を継続。

### 移設中の90度回転

選択後の「↻ 90°回転」またはRキーで、選択全体を時計回りに90度ずつ回す。選択設備を囲む長方形の左上を固定し、縦横サイズを交換する。移動先指定後も同じ左上位置で回転でき、その場での回転確定も可能。角度は操作バーに表示し、4回で元に戻る。
レーン・分岐器の出口、猫の取る側と渡す側、搬送中の食材の方向も回転する。立体交差は奇数回転で縦横の食材を交換する。在庫・フィルター・調理途中・食事時間・費用は保持。プレビューは元の設備を変更せず、確定時だけ一括反映する。回転先の衝突・敷地外は従来同様に拒否。取消・再読み込みは未確定の回転を破棄する。

## 調理台の自動搬送と猫の仕分け（2026-11-05）

- 全調理台は上下左右のレーン・分岐器・立体交差から使用可能な材料を毎ステップ最大1個取得。材料ごとの上限4個を守り、不要材料・斜めの材料は取らない。立体交差は接する軸だけを扱う。
- 入荷箱と調理台は指定出口の隣のレーン類へ毎ステップ最大1個自動搬出。空きがなければ待つ。配置時の向き、設備情報の「出口 ↻」、範囲回転が搬出方向に反映される。盤面には出口矢印、設備情報には自動取得と搬出方向を表示する。
- 調理台の取得はレーン移動より先。開始時点の食材だけを対象にし、自動搬出直後の食材を同一ステップで再搬送・取得しない。搬出と猫が競合しても設備の完成品は1個だけ取り出す。調理台の取得方向と設備の優先順を巡回する。
- 猫は指定材料を取り分ける役として存続。指定なしの従来搬送、取り出し方向・渡す方向、客席への直接配膳も保持。保存済みの猫を勝手に削除しない。既存の猫をレーンへ置き換えて猫なしのラインにもできる。
- 調理時間、価格、費用、保管上限、客席の3秒の食事時間、保存形式v2は維持。旧保存はそのまま読み込む。調理台に使えない材料がレーンを塞いだ場合は、猫のフィルターなどで別経路へ分ける。

## 猫なしの初期配置と導入ガイド（2026-11-06）

- 新規ゲームは従来の搬送猫7体を同じ向きのレーンに置き換え、米→炊飯と魚→仕込みを握り台につないだ状態で停止開始。点線の(9,5)に右向きレーンを1本置けば提供まで進む。資金500円、費用・調理時間・注文目標は従来通り。
- 新規データだけに任意の識別子 `tutorial: auto-v1` を付ける。保存形式v2と保存キーを継続し、旧データの配置・猫・設定・材料・資金は変更しない。
- 画面内ガイドは「1/3 接続」「2/3 稼働」「3/3 最初の提供」、成功後は20皿の注文と設備情報を案内。まぐろ注文達成後は猫の仕分け設定を紹介する。
- 導入マスの向き違いは修正を案内。初期ラインの変更や設備追加をした場合は固定位置への案内をやめ、自由改良の説明へ切り替える。旧保存には新規用の固定マス案内を表示しない。
- 再読み込みでは保存配置を停止状態で復元し、接続済みなら稼働の案内から続ける。新しい工場を確定した場合だけ初期配置と導入ガイドをリセットする。
