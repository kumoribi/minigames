WORKSHOP GUIDE

小さな猫の、大きな工場。

材料と調理台をつなぎ、自動で寿司が届く店をつくろう。まずは光る空きマスにレーンを置いて、稼働！

生産の流れ

米 → 炊飯釜 → シャリ
魚 → 仕込み台 → ネタ
シャリ ＋ ネタ → 握り台 → 客席
シャリ ＋ 切ったきゅうり ＋ 海苔 → 巻き寿司台

猫が設備をつなぎます

入荷箱・調理台から取り出すとき、調理台に入れるときは「おてつだい猫」が必要です。猫は隣の1マスから取り、別の隣接マスへ渡します。猫の青い印が取る側、矢印が渡す側。猫を選ぶと両方を変更できます。客席は上下左右のレーンを通る完成皿を自分で取ります。猫が客席に直接渡すこともできます。客席は1皿取るとゲーム内で3秒間は食事中になります。その間、次の皿はレーンを通過し、猫からの直接配膳も待ちます。客席を選ぶと残り時間を確認できます。一時停止中は食事時間も止まり、保存後は残り時間から再開します。仕込み台は届いた魚やきゅうりを切り、握り台はシャリと届いたネタで寿司を握ります。両方のネタがそろうと交互に握ります。

レーンと仕分け

矢印の方向に1マスずつ搬送。ドラッグで連続配置すると曲がり角もつながります。合流先が満杯なら待ちます。分岐器は直進・左折へ交互に振り分け、フィルターを選ぶと指定食材だけ左折。立体交差は縦と横が独立して通り、入ってきた向きを保ちます。

操作

操作と情報はすべて盤面内に表示されます。「建設」で設備一覧を開き、設備を選ぶと一覧が閉じて配置できます。「移動」で設備をタップすると詳細が開き、×で閉じられます。上部の注文を押すと解放条件、☰で保存状況・新規開始・ゲーム集へのリンクを確認できます。パネル内の長い内容だけスクロールでき、ページ全体はスクロールしません。「移動」でドラッグすると盤面が移動します。＋・−または2本指で拡大縮小。「全体」で敷地全体を表示。建設中の1本指ドラッグは配置です。PCはホイールで拡大縮小、Rで配置方向を回転、Escで移動モード。盤面にフォーカスすると矢印キーとEnterでも操作できます。

困ったときは

設備を選ぶと材料待ち・出口満杯を確認できます。調理台は各材料4個、完成品4個まで保管。食材の入荷は無料です。撤去は建設費を全額返却しますが、中の食材と調理途中の材料は廃棄されます。新しいラインを増やす資金は寿司の提供と注文達成で獲得します。

目標と保存

まぐろ20皿 → サーモン20皿 → かっぱ巻き20皿で設備と敷地を解放。最後の注文達成後も自由に建設できます。制限時間・ゲームオーバーはありません。

このブラウザに5秒ごとと建設・停止時に自動保存します。再読み込みとタブを離れたときは停止し、不在中の生産は行いません。プライベートブラウズや保存領域の削除で記録が失われることがあります。保存に失敗した場合は画面内の保存表示と通知で知らせます。詳細は☰メニューで確認できます。
