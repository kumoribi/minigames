# キングダムスイーパー

20×20の数字から敵の位置を推測し、領土と軍備を整えてDragonを討つ探索RTSのMVP。

## 起動

ミニゲーム集トップの「キングダムスイーパー」を選択するか、このフォルダの`index.html`をブラウザで開く。ローカルファイルでも動作する。公開先は https://kumoribi.github.io/minigames/kingdom-sweeper/ 。

## 最初の進め方

1. 開始前に平地へ農場・兵舎を建築予約する（新しい王国も開始前から）。
2. 「ゲーム開始」を押すと通常速度で進行する。開始後の停止・倍速はない。Workerは空き時間に資源を採集する。
3. 兵舎を選択してSoldierを育成。人口上限なら民家を追加する。
4. 未探索マスを開拓し、数字を手がかりに敵拠点へ備える。
5. 1:30以降は未封印拠点から敵が出撃。正しい旗で封印し、誤旗を避ける。攻略するなら旗を維持して明示的な拠点攻略を予約。旗なし開拓は強化部隊を招く。
6. 侵攻を迎撃しながらDragonを意図的に起こして討伐する。

スマホは「地図移動」モードのドラッグと＋／−で地図を操作する。タブを離れた間だけ安全のため自動停止し、戻ると自動再開する（離れていた時間の追いつき処理なし）。再読み込み・新しい王国では進行がリセットされる。

## 現行ルール：通常速度・キャラクター衝突（2026-10-22）

以下は古い停止・速度関連の記録より優先。ゲーム開始後はSpace・ヘルプ・宝箱・再開始確認・設営支援を含め、任意停止や倍速を行わない。報酬は閉じても保留され、HUDの「報酬」から再表示できる。結果確定後は進行停止。開始前の予約は可能。

Worker・Soldier・Goblin・Dragonは味方／敵を問わず、中心を基準とする正方形の占有範囲を共有する。半幅は順に0.44・0.56・0.56・1.16マス。描画の踏み込み・上下動を含む余白を確保し、画像サイズ・HP・攻撃力・基礎移動速度は維持。HP表示や攻撃粒子・消滅残像は占有範囲に含めない。建物との衝突ではなくキャラクター同士の衝突。

出現時は近傍の空きを探し、なければ育成済みユニットは支払い済みの列で、敵は出現待ちで保持する。空きができれば再試行し、重ねて出現させない。出撃集計は発行数で、出現待ちも含む。味方の中心は開拓済み領土内に制限し、敵は霧を進める。迂回・作業者への道譲り・集合地点周辺への分散を行い、集合済み兵士の判定は地点から3マス以内。接近戦は互いの占有範囲の端まで届く距離で判定する。物理的に空間がない場所では待つため、開拓や集合地点変更で通路を広げる必要がある。

自動49シナリオ成功。100シードの初期・敵出現、育成／敵出現の空き待ち、作業者の採集と開拓、10兵士の集合、Dragonとの接触戦闘、味方20体＋敵20体の混戦を検証。旧版の速度別比較・勝率は現行の実測とは扱わない。キャッシュv52。

- `renderer.js`: Phaserのシーン、画像・数字の描画、Tween・粒子・被弾・建築・消滅演出。ゲームルールは持たない。
- `vendor/`: MITライセンスのPhaser 3.90.0固定版とライセンス文。配信時のCDN依存はない。
- `style.css` / `index.html`: レスポンシブ画面。
- `assets/`: ユーザー提供PNGを加工した18素材。元画像は変更しない。
- `tests.cjs`: `node tests.cjs`で49シナリオ。従来の生成・侵攻・シナジー・報酬・戦闘・王城防衛に加え、通常速度固定・衝突・出現待ち・分散集合を検証。

風車は8近傍の農場生産×1.25、鍛冶屋は4近傍の兵舎で育成完了した兵士の攻撃・HP×1.2。同種の隣接効果は重複しない。

進行保存・永続ローグライト強化、新地形・敵種類は今後の拡張。

## 判断を増やす改善・第1段階（過去の記録）

- 取得後は明示的に停止し、宝箱の場所を中心に塔の配置モードへ移る。「1×」等で建築を再開する。配置せず他の操作に戻っても支援は保持。「この王国の強化」から再び配置モードへ移れる。数値強化は従来どおり選択前の速度で再開。複数宝箱は順に選び、支援取得後の次の宝箱は射程強化になる。
- 建築予約時に支援を確保。取消時は支援だけ返し、資源は払い戻さない。有料の予約は予約時に実際に支払った費用を返す。支援取得前の有料予約、支援予約中の2棟目の有料予約も区別する。実支出の集計に無料分は含めない。未使用・予約中・設営済みを表示し、新しい王国でリセットする。
- 生成v2・敵と兵士の能力値・宝箱の資源報酬は変更なし。キャッシュv48。未出現敵の休眠と安全待機による軍備蓄積は残る。

## Phaser描画

描画とメインループをPhaser 3.90.0へ移行。既存のHTML操作パネルと独立したゲーム計算は維持する。WebGLが利用可能ならWebGL、利用不可・file起動時はPhaserのCanvas描画を使用する。

既存の静止画素材で、移動時の上下動・傾き・左右向き、攻撃時の踏み込み、被弾時の短い色変化、倒されたユニットの消滅、建築完成時の立ち上がりを表現する。連続コマ画像による歩行アニメーションではない。塔は飛翔体、兵士・ゴブリンは斬撃、ドラゴンは火色の飛翔体と粒子。HP減少は従来どおりシミュレーション時点で確定し、着弾演出の待ち時間で遅延しない。

## リデザイン

- スマホは下部の開拓・建築・軍備・旗・移動バーから操作。建築と選択情報は地図に重なるパネルで表示し、作業予約の確認・取消も可能。PCは右側パネルを維持。
- 6段階の進行ガイド（折りたたみ可能）、建築の仮表示・進捗、選択中の作業員経路、シナジー接続を表示。
- 開拓時の霧解除、建築完了、採集、兵士の斬撃・塔の弾・ドラゴンの攻撃を区別。演出寿命は実時間で管理し、最大60イベント、戦闘バランスには影響しない。
- 襲撃方向ボタンから王城に最も近い敵へ移動。ドラゴンHPバー、作業員の退避表示を追加。
- 宝箱は基本値の取得前後と現存する対象数を比較。勝敗結果に現存建物数・生存兵士数を表示。
- 効果音は初期OFF。演出軽減チェックとOSのモーション軽減に対応。勝敗表示の待ち時間も軽減時は短縮。
- ユニット画像は地図100%で作業員42px、兵士・ゴブリン50px、ドラゴン108px。HPバーも拡大し、危険度の数字は画像・演出より手前に描画。移動・攻撃範囲の計算は変更しない。
- 進行ガイドは達成した段階を記憶するが、この王国限り。3兵士は操作説明の目安であり、敵を必ず倒せる保証ではない。
