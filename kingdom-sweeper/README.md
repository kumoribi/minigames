# キングダムスイーパー

20×20の数字から敵の位置を推測し、領土と軍備を整えてDragonを討つ探索RTSのMVP。

## 起動

ミニゲーム集トップの「キングダムスイーパー」を選択するか、このフォルダの`index.html`をブラウザで開く。ローカルファイルでも動作する。公開先は https://kumoribi.github.io/minigames/kingdom-sweeper/ 。

## 最初の進め方

1. 開始前に平地へ農場・兵舎を建築予約する（新しい王国も開始前から）。
2. 開始時から0の周囲は自動で開拓予約される。「ゲーム開始」で通常速度進行。手動の建築・開拓を優先し、Workerは空き時間に資源を採集する。開始後の停止・倍速はない。
3. 兵舎を選択してSoldierを育成。人口上限なら民家を追加する。
4. 未探索マスを開拓し、数字を手がかりに敵拠点へ備える。
5. 1:30以降は未封印拠点から敵が出撃。正しい旗で封印し、誤旗を避ける。攻略するなら旗を維持して明示的な拠点攻略を予約。旗なし開拓は強化部隊を招く。
6. 侵攻を迎撃しながらDragonを意図的に起こして討伐する。

スマホは「地図移動」モードのドラッグと＋／−で地図を操作する。タブを離れた間だけ安全のため自動停止し、戻ると自動再開する（離れていた時間の追いつき処理なし）。再読み込み・新しい王国では進行がリセットされる。

## 現行ルール：通常速度・キャラクター衝突（2026-10-22）

### 誤旗攻略のミニドラゴン（現行・v65）

未探索の安全マス（danger=0）に旗を維持したまま拠点攻略／集結攻略を完了すると、ミニドラゴン1体を出現させる。旗だけでは出さず、誤旗からの定期ゴブリン出撃は従来どおり。通常開拓・旗なし攻略・正しい拠点攻略・本物のDragonには追加出現なし。同じマスを再度開いて複製できない。初期危険度・数字を書き換えず、資源地形は維持し、宝箱の通常資源／3択報酬も維持する。

基本HP300・攻撃14・速度1.2マス/秒・攻撃間隔1.4秒。HP・攻撃は2乗の領土倍率を適用し、全解放でHP1500・攻撃70。既存個体の負傷割合維持も通常敵と共通。画像は既存Dragonを60%（64.8px）表示し、円半径も60%。赤いHPバーと「ミニドラゴン」のラベルで区別。炎攻撃・出現演出・出現時／移動中／近接時の押しのけを持ち、押し出せないときは重ねず出現待ち。未開拓地・マップ外に味方を押し込まない。塔・兵士・Worker・王城を通常の敵AIに従って攻撃する。

miniDragonはdragonとは別種として扱い、撃破時は通常Gold6のみ。勝利・王国のDragon覚醒・ボスHP表示・拠点戦利品の対象にしない。本物のDragonの勝利・Gold150は維持。自動114件（旧105＋9）で出現条件、成長、資源／宝箱維持、押しのけ・出現待ち・非重複、速度・間隔・塔攻撃、報酬・勝利分離、Workerによる両攻略、停止と端を確認。新画像ファイルは不要。engine24/game21/renderer11、キャッシュv65。

### 旗付き拠点攻略の戦利品（現行・v64）

実際の敵拠点（danger=1）に旗を維持し、拠点攻略／集結攻略を完了して開いた場合、その攻略で生成した全3～5体のゴブリンを倒すと、1拠点につき一度だけFood+30・Wood+30・Gold+15を追加獲得。通常討伐のGold6/体は別途維持する。旗を立てただけ、誤旗、安全地、旗なし・通常開拓、Dragon、定期出撃の敵は戦利品の対象外。以前その拠点から定期出撃した敵が生存していても、攻略部隊とは区別する。

攻略敵には出身の攻略拠点を記録し、出現待ちにも同じ識別を保持。出現待ちが残る間は報酬を確定せず、複数拠点はそれぞれ独立判定する。獲得済み記録はその王国だけに保持し、再開拓・旗操作・予約取消で再獲得させない。開始前・背景停止・結果確定後は新たな判定をしない。拠点選択時に出現待ちを含む残存数と報酬額／獲得済みを表示し、獲得時に資源HUD・通知・記録・金粒子演出で知らせる。演出軽減に対応。

自動105件（旧98＋7）：部分撃破と全滅・通常討伐併給・一度限り、対象外、全員出現待ち、既存定期敵の分離、複数拠点、再操作と新王国初期化、停止・終了後の禁止を確認。engine23/game20/renderer10、キャッシュv64。

### 開拓予約の一括操作（現行・v63）

予約パネルの「開拓予約を全解除」は作業中を含む通常・自動・拠点攻略・集結攻略の全開拓予約を取り消し、担当Workerを解放する。建築・育成予約、確保済み資源・設営支援、旗、解放済みの領土は変更しない。取り消したマスの自動予約抑止は個別取消と同じで、別の0を発見しても勝手に復活させない。

### 兵士の攻撃対象の切替（現行・v62）

敵の中心マスが未開拓、または公開地を通る4近傍経路がない場合は、その敵を選ばず到達可能な次の敵へ向かう。すでに近接攻撃が届く敵への自衛は優先する。接近中の目標は保持して往復を抑えるが、敵との距離を累計0.1マス以上更新できない時間が2秒続けば、その敵を3秒間候補から外して選び直す。単なる攻撃間隔待ちは足止めとしない。除外期限後は再び候補となり、倒された敵の履歴は削除。全候補が到達不能／除外中なら道を譲る・集合地点へ戻る。防衛範囲と範囲外での自衛、未開拓地への移動禁止、能力・敵強化・回復・押しのけは維持。

自動92件成功（従来86＋6）：未開拓／分断の近い敵を飛ばす、密集による足止めから別の敵へ切替・実攻撃、3秒除外と再攻撃、接触時の攻撃待ち／自衛、全候補到達不能時の集合復帰、防衛制約と死亡履歴削除。毎tick非重複を確認。engine21、キャッシュv62。

### 終盤加速の敵強化（現行・v61、以下の線形倍率より優先）

領土進捗 `p = clamp((解放数 - 9) / 391, 0, 1)` に対し、敵倍率を `1 + 4 × p²` とする。9マス1倍、100マス約1.22倍、200マス約1.95倍、300マス約3.22倍、350マス約4.04倍、400マス5倍。序盤は緩やかで、1マス追加ごとの増分が終盤ほど大きくなる。HP・攻撃への適用、既存／出現待ちの負傷割合維持、強襲2倍の乗算、兵士の80%衝突円・回復はv60と同じ。倍率表示は共通の計算式を使用する。自動86件で各途中値・全解放5倍、10～400マスの増分の単調増加、既存の戦闘・回復・非重複を確認。engine20、キャッシュv61。

### 領土による敵強化・兵士調整（現行・v60、以下の旧記録より優先）

敵のHP・最大HP・攻撃力は、倍率 `1 + 4 × clamp((解放数 - 9) / 391, 0, 1)` を基本値に掛ける。初期9マスで1倍、100マス約1.93倍、200マス約2.95倍、300マス約3.98倍、400マスで5倍。ゴブリン・Dragon・出現待ち・既存個体すべてに適用し、負傷した個体は残りHP割合を維持。開拓予約・旗は解放数に数えない。旗なし拠点の強襲2倍と乗算し、全解放時の通常ゴブリンはHP240／攻撃35、強襲はHP480／攻撃70、DragonはHP6000／攻撃140。移動速度・攻撃間隔・出現数は不変。領土地図の見出しに現在の敵倍率を表示。

兵士のみ円の半径・直径を旧値の80%へ縮小し、画像50pxは維持。近接距離・出現・押しのけも同じ縮小した円を利用。他のユニットの円は変更しない。兵士は敵と近接しておらず最後の攻撃／被弾から3秒以上経過すると、移動・待機中とも毎秒HP1を時間に比例して回復。鍛冶屋強化を含む本人の最大HPまでで、Worker・敵・建物は回復しない。開始前・背景停止・終了後・死亡後は回復しない。

### Dragonの押しのけ（現行・v59）

Dragonは移動・対ユニット近接戦闘中にWorker／Soldierを円形判定の外へ少しずつ押す。押すこと自体の追加ダメージはなく、攻撃28・間隔1.4秒・HP1200・基本速度1を維持。連なる味方も短い範囲で押すが、未開拓地・マップ外・他の敵などで移動できなければ、その押し処理全体を戻して迂回／待機する。建物、ゴブリン、衝突判定を失った待避Workerは押さない。命令は維持し、移動経路や作業位置だけを再選択する。

登場時も巣の周囲の味方を徐々に押し広げ、円形判定が収まってから実体化する。端の巣は判定がマップ内に収まる位置へ補正。空間がなければ出現待ちを継続し、離れた場所への瞬間出現はしない。待機中の出現範囲へ味方がさらに入り込む動きを制限する。押しのけに砂ぼこり、出現に炎と衝撃波を表示し、演出軽減設定では拡大アニメーション・粒子を省く。

### 敵による監視塔攻撃（現行・v57）

塔の被害は地図上のHPバー、選択情報のHPと着弾演出で表示する。HP0になった攻撃の直後に建物を除去し、自動攻撃停止・破壊通知と演出を1回だけ発生。次の敵も同tickから破壊済み塔を対象にしない。跡地は開拓済みの平地として残り、敵との距離1.5マス以上・通常費用Wood60/Gold15・Worker建築8秒など従来条件で再建可能。設営支援は破壊で返らず、取得済み射程強化は王国に残る。王城以外の塔の喪失だけで敗北にはしない。

### 円形判定と待機Worker（現行・v54、以下の旧正方形規則より優先）

### 移動詰まり対策（現行・v53）

採集・建築では中心1点を目指さず、周囲の開拓済み位置をWorkerごとに予約する。作業基準点から1.36マス以内（開拓は従来の隣接作業マスを基準）、到着許容0.18マス。塞がった予約は0.8秒後に取り直す。資源量・採集毎秒2・建築所要時間・HP・攻撃力・基礎速度・占有サイズは維持。

実際の進行先を塞ぐ味方に、建築／開拓Worker＞採集Worker＞移動兵士＞待機兵士の順で待避要求する。同優先は小さいIDを先にし、移動中の兵士同士は迂回を優先して相互待避を抑える。戦闘・Workerの避難は待避より優先。待避位置も重ならないよう選び、最大1.8秒の要求中は通路へ即座に戻らない。退く側が連鎖要求することを抑止する。

- 生成v2・敵と兵士の能力値・宝箱の資源報酬は変更なし。キャッシュv48。未出現敵の休眠と安全待機による軍備蓄積は残る。

## Phaser描画

描画とメインループをPhaser 3.90.0へ移行。既存のHTML操作パネルと独立したゲーム計算は維持する。WebGLが利用可能ならWebGL、利用不可・file起動時はPhaserのCanvas描画を使用する。

既存の静止画素材で、移動時の上下動・傾き・左右向き、攻撃時の踏み込み、被弾時の短い色変化、倒されたユニットの消滅、建築完成時の立ち上がりを表現する。連続コマ画像による歩行アニメーションではない。塔は飛翔体、兵士・ゴブリンは斬撃、ドラゴンは火色の飛翔体と粒子。HP減少は従来どおりシミュレーション時点で確定し、着弾演出の待ち時間で遅延しない。

## リデザイン

- スマホは下部の開拓・建築・軍備・旗・移動バーから操作。建築と選択情報は地図に重なるパネルで表示し、作業予約の確認・取消も可能。PCは右側パネルを維持。

- 開拓時の霧解除、建築完了、採集、兵士の斬撃・塔の弾・ドラゴンの攻撃を区別。演出寿命は実時間で管理し、最大60イベント、戦闘バランスには影響しない。
- 襲撃方向ボタンから王城に最も近い敵へ移動。ドラゴンHPバー、作業員の退避表示を追加。
- 宝箱は基本値の取得前後と現存する対象数を比較。勝敗結果に現存建物数・生存兵士数を表示。
- 効果音は初期OFF。演出軽減チェックとOSのモーション軽減に対応。勝敗表示の待ち時間も軽減時は短縮。
- ユニット画像は地図100%で作業員42px、兵士・ゴブリン50px、ドラゴン108px。HPバーも拡大し、危険度の数字は画像・演出より手前に描画。移動・攻撃範囲の計算は変更しない。
- 進行ガイドは達成した段階を記憶するが、この王国限り。3兵士は操作説明の目安であり、敵を必ず倒せる保証ではない。
