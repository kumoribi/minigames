# キングダムスイーパー

20×20の数字から敵の位置を推測し、領土と軍備を整えてDragonを討つ探索RTSのMVP。

## 起動

ミニゲーム集トップの「キングダムスイーパー」を選択するか、このフォルダの`index.html`をブラウザで開く。ローカルファイルでも動作する。公開先は https://kumoribi.github.io/minigames/kingdom-sweeper/ 。

## 最初の進め方

1. 開始時は停止状態。平地に農場・兵舎を建築予約する（新しい王国も停止から開始）。
2. 1×〜4×で進行させる。Workerは空き時間に資源を採集する。
3. 兵舎を選択してSoldierを育成。人口上限なら民家を追加する。
4. 未探索マスを開拓し、数字を手がかりに敵拠点へ備える。
5. 兵士と監視塔を整え、Dragonを意図的に起こして討伐する。

スマホは「地図移動」モードのドラッグと＋／−で地図を操作する。タブを離れると停止する。再読み込み・新しい王国では進行がリセットされる。

## 構成と検証

- `engine.js`: 乱数生成、経路、予約、資源、育成、自動戦闘、勝敗。
- `game.js`: UI、シミュレーション進行、ポインター・キー操作。
- `renderer.js`: Phaserのシーン、画像・数字の描画、Tween・粒子・被弾・建築・消滅演出。ゲームルールは持たない。
- `vendor/`: MITライセンスのPhaser 3.90.0固定版とライセンス文。配信時のCDN依存はない。
- `style.css` / `index.html`: レスポンシブ画面。
- `assets/`: ユーザー提供PNGを加工した18素材。元画像は変更しない。
- `tests.cjs`: `node tests.cjs`で29シナリオ、500シードの生成比較、シナジー・宝箱・戦闘・防衛・準備予約・損失と支出・設営支援の取得と建築と取消を検証。

風車は8近傍の農場生産×1.25、鍛冶屋は4近傍の兵舎で育成完了した兵士の攻撃・HP×1.2。同種の隣接効果は重複しない。

宝箱は資源と3択報酬（農場+25%／全兵士攻撃+20%／塔射程+30%）。塔がなく設営支援を未取得なら3枠目を初回の塔1棟の設営支援へ切り替える。選択中は停止し、その王国だけで有効。数値強化は加算で累積し、シナジーとは乗算。「この王国の強化」で取得と支援状態、建物選択で効果範囲・有効状態を確認できる。

進行保存・永続ローグライト強化、新地形・敵種類は今後の拡張。

## 判断を増やす改善・第1段階

- 選択情報の「兵士の行動」で自動追撃（初期値）／集合地点防衛を切り替える。防衛では集合地点の半径3マスにいる敵を迎撃し、敵がいなくなると集合地点へ戻る。範囲外でも接近された場合は近接自衛する。防衛範囲を緑の円で表示する。移動・攻撃の能力値は従来どおり。
- 防衛中に旗付き未探索マスを選び、必要人数1〜10体を指定して「集結後に開拓予約」。対象は予約時の集合地点から半径3マス内。指定人数の生存兵士が同地点から1マス以内へ集結するまで待つ。作業中に条件を失った場合も進捗を保持して中断し、Workerを解放する。集合地点を変更した場合は元に戻すか取消。兵士がいなくても採集・他の予約は継続できる。旗の正誤を判定する機能ではない。
- 数字0の周囲をまとめて予約できる。未探索・旗なし・未予約のみで、隠れた危険度は参照しない。Workerの3秒作業と接続判定は維持。移動中の敵への安全保証はない。
- 結果に損失・育成完了数・Wood/Food/Goldの実支出を表示。建築取消の返金を差し引き、育成待ちの支払いは含める。初期Worker3は育成数に含めない。時間による減点・進行保存はない。同じシードで停止状態から再挑戦できる。
- 生成処理・宝箱の固定3択・兵士と敵の能力値は変更していない。資源地帯と推理経路の生成設計、宝箱の攻略手段化は次の段階とし、この段階だけで物量戦略を解消したとは扱わない。

## 第2段階：目的を選べる資源地帯と推理経路

- 通常は王城の北・東・南・西から3方向を選び、距離6〜7の場所へ森林・食料・鉱山をそれぞれ集める。候補区画は3×3、同種の採集可能な資源4マス以上。資源の種類・残量を既存のマスと交換して作るため、総量を増やさない。初期5×5の内容は維持する。
- 既存の敵拠点を移動し、各資源地帯へ数字0の続く経路を用意する。通路の周囲8マスも初期危険なし。Dragonは移動しない。短い接近候補にも既存の拠点を配置する。敵の数・拠点ごとの出現Goblin総数を保つため、移動先は同じ`id % 3`のマスとする。数字は最後に再計算する。
- 経路は初期から一方向へ2マス、横へ4マス、外側へ進み、資源区画へ戻る形を回転・反転する。長い経路を安全確認しながら進むか、短い接近候補の敵を攻略するかを選ぶ。これは候補経路の設計であり、全ての最短経路を敵で封鎖したり、唯一の二択を強制するものではない。ほかの安全な近道が見つかる場合もある。
- 「探索先の候補」のボタンで区画へ移動。紫枠と資源種類・区画の位置は公開調査情報であり、未開拓の内容や安全経路、敵位置、全区画の安全は公開・保証しない。候補の選択で開拓を自動予約しない。
- 地形・兵種・戦闘能力・宝箱3択・維持費は変更しない。生成方式はv2。同じ番号でも旧版と配置は変わるが、この版の再挑戦は再現する。検証用`create(seed,{structured:false})`で旧生成を比較できる。経路構成ができない場合は元の有効な生成を保持し、資源4マスを確保できない種類は候補表示しない。
- 全盤面・Dragon位置の無推測クリアは保証しない。未出現の敵は休眠、無限待機での軍備増強は従来どおり。安全な範囲の拡大が慎重攻略に偏りすぎないか、人間のプレイで引き続き評価する。

## 第3段階：宝箱で前線の設営を選ぶ

- 宝箱は常に3択。農場生産+25%と全兵士攻撃+20%は維持。生存する塔がなく支援未取得のときだけ、3枠目を射程+30%から「前線設営の支援」に切り替える。塔所有中、支援取得後（未使用・予約中も含む）は従来の射程強化。選択肢以外の報酬の直接要求は拒否する。
- 支援は1王国1回。次の監視塔1棟のWood60・Gold15を免除するが、開拓済み空き平地・敵との距離1.5以上・Worker移動・8秒の建築時間は通常どおり。塔のHP300・攻撃14・射程3・攻撃間隔1秒は変更しない。射程強化は支援の塔にも適用する。
- 取得後は明示的に停止し、宝箱の場所を中心に塔の配置モードへ移る。「1×」等で建築を再開する。配置せず他の操作に戻っても支援は保持。「この王国の強化」から再び配置モードへ移れる。数値強化は従来どおり選択前の速度で再開。複数宝箱は順に選び、支援取得後の次の宝箱は射程強化になる。
- 建築予約時に支援を確保。取消時は支援だけ返し、資源は払い戻さない。有料の予約は予約時に実際に支払った費用を返す。支援取得前の有料予約、支援予約中の2棟目の有料予約も区別する。実支出の集計に無料分は含めない。未使用・予約中・設営済みを表示し、新しい王国でリセットする。
- 生成v2・敵と兵士の能力値・宝箱の資源報酬は変更なし。キャッシュv48。未出現敵の休眠と安全待機による軍備蓄積は残る。

## Phaser描画

描画とメインループをPhaser 3.90.0へ移行。既存のHTML操作パネルと独立したゲーム計算は維持する。WebGLが利用可能ならWebGL、利用不可・file起動時はPhaserのCanvas描画を使用する。

既存の静止画素材で、移動時の上下動・傾き・左右向き、攻撃時の踏み込み、被弾時の短い色変化、倒されたユニットの消滅、建築完成時の立ち上がりを表現する。連続コマ画像による歩行アニメーションではない。塔は飛翔体、兵士・ゴブリンは斬撃、ドラゴンは火色の飛翔体と粒子。HP減少は従来どおりシミュレーション時点で確定し、着弾演出の待ち時間で遅延しない。

一時オブジェクトは最大60、粒子は4エミッター各96個まで。画面外の追加演出は抑制。1×〜4×でも演出時間は実時間基準。停止中・宝箱選択中は歩行を止め、再開・新王国で二重ループを作らない。演出軽減時は揺れ・踏み込み・粒子・被弾色変化を止め、輪郭・文字・HP表示を残す。

Phaser配布元: https://cdn.jsdelivr.net/npm/phaser@3.90.0/dist/phaser.min.js 。ライセンス: `vendor/PHASER-LICENSE.txt`。同梱ファイルSHA-256: `e92ddef111ba42e92d316979c732311757093688ea1810591cb7aa2858eba7a7`。

推奨するローカル確認は、このミニゲーム集フォルダをHTTPサーバーで提供する方法。`python -m http.server 8000 --bind 127.0.0.1`をこのフォルダで実行し、`http://127.0.0.1:8000/`を開く。

## リデザイン

- スマホは下部の開拓・建築・軍備・旗・移動バーから操作。建築と選択情報は地図に重なるパネルで表示し、作業予約の確認・取消も可能。PCは右側パネルを維持。
- 6段階の進行ガイド（折りたたみ可能）、建築の仮表示・進捗、選択中の作業員経路、シナジー接続を表示。
- 開拓時の霧解除、建築完了、採集、兵士の斬撃・塔の弾・ドラゴンの攻撃を区別。演出寿命は実時間で管理し、最大60イベント、戦闘バランスには影響しない。
- 襲撃方向ボタンから王城に最も近い敵へ移動。ドラゴンHPバー、作業員の退避表示を追加。
- 宝箱は基本値の取得前後と現存する対象数を比較。勝敗結果に現存建物数・生存兵士数を表示。
- 効果音は初期OFF。演出軽減チェックとOSのモーション軽減に対応。勝敗表示の待ち時間も軽減時は短縮。
- ユニット画像は地図100%で作業員42px、兵士・ゴブリン50px、ドラゴン108px。HPバーも拡大し、危険度の数字は画像・演出より手前に描画。移動・攻撃範囲の計算は変更しない。
- 進行ガイドは達成した段階を記憶するが、この王国限り。3兵士は操作説明の目安であり、敵を必ず倒せる保証ではない。
